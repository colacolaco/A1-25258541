==========================================================================================
THE FIXED DAILY SCHEDULE IS FLEXIBLE
==========================================================================================
Standard schedule: 08:00-16:00, 30 minute appointments, 16 slots per day
Longer day:        07:00-19:00, 30 minute appointments, 24 slots per day
20 minute slots:   09:00-17:00, 20 minute appointments, 24 slots per day

A different schedule object can be passed to the Clinic constructor;
addAppointment then validates times against it with no other change.

==========================================================================================
INVALID DATA IS REJECTED BEFORE AN OBJECT IS BUILT
==========================================================================================
  WARNING: a health professional ID must contain numbers only, but was "12A".
  WARNING: a mobile number must be 10 digits starting with 04, but was "12345".
  WARNING: the minute must be between 0 and 59, but was 75.

Each check returns a message instead of causing an error, so the program
can show the message to the user and carry on with the valid data.
